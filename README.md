## How to Run
1. Extract the project folder.
2. Open `index.html` in a browser.
3. For best development experience, open the folder in VS Code and use Live Server.

No build step is required.

## Important
The contact form uses a public demo endpoint only to demonstrate the Fetch API. For a real portfolio, replace it with a backend, Formspree, EmailJS, or another approved form service.

## Assignment Notes
The public portfolio intentionally contains professional/academic information only. Private personal details such as parents' names, date of birth and gender are not displayed.
